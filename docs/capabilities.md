# Capability preservation

The previous 0.2 redesign and migration proposal has been withdrawn. The current implementation retains the original 0.1 typed schema, Serde/XML editing and output, strategy/validator APIs, C# routing, independent package/namespace options, original commands and existing compiler/JAR workflows.

This file no longer describes an ordered read-only model or a new validation/evolution engine as delivered behavior. Those replacements were rolled back. See [current status](implementation-status.md) and the [revised plan](implementation-plan.md) for retained compiler/build work and future proposals.
